# Postulaciones

Responsable de envíos, unicidad, consulta, retirada y evaluación. Ver APP-01 y APP-02 en `docs/ROADMAP.md`.

Implementar aquí controlador, validaciones, servicio y repositorio. Usar las fachadas de `jobs` para comprobar publicación/propiedad dentro de una transacción y de `users` para información de candidatos.

Consumir estados y transiciones de `@conecta/contracts`; el permiso de cada transición depende del actor. Las rutas actuales son placeholders 501.
