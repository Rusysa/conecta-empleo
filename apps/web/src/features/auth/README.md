# Interfaz de acceso

Implementar registro e inicio/cierre de sesión usando `/auth/*`. Formularios, hooks y pruebas de autenticación pertenecen aquí; la composición de rutas va en `src/app/`.

Usar el cliente HTTP de `src/shared/api.js` y añadir soporte de CSRF cuando el backend implemente sesiones. No guardar tokens de sesión en localStorage.
